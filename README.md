# OS Trading · Indicateurs TradingView

Indicateurs Pine Script (TradingView) développés par **OS Trading** pour le trading intraday : ICT / Smart Money Concepts, TheStrat, price action.

## Indicateurs

| Indicateur | Description | Marchés testés | Version |
|---|---|---|---|
| [CC Model PRO](./indicators/cc-model-pro/) | Modèle CC (Candle Confirmation) de TheStrat + filtre de biais ICT BOS/CHoCH + entrée, SL, TP et lot affichés | NAS100, XAUUSD | 1.0 |

## Installation rapide

1. Ouvre le dossier de l'indicateur, puis le fichier `.pine`.
2. Clique sur **Copy raw file**.
3. TradingView → **Pine Editor** → **Ouvrir** → **Nouvel indicateur** → colle → **Enregistrer** → **Ajouter au graphique**.

Le mode d'emploi complet de chaque indicateur est dans son dossier.

## Avertissement

Outils d'aide à la décision, pas des conseils en investissement. Teste en bar replay ou en démo avant de trader réel.
